# Last Call: shared brief for every agent

Read this whole file before touching code. Do not edit this file.

## The user's goal

A polished, original three.js browser card game in the bluffing-plus-revolver genre. It's playable at a
Cloudflare Worker URL. The user asked for graphics that look polished and good while staying performant,
animations that are "super smooth", a camera that really looks around (not a pan), and a finished
product rather than a quick demo. They will judge it by playing it in a desktop browser on a real GPU.

## Hard constraints

- **Originality.** This is an original game in a genre. Never imitate a specific commercial game's
  characters, art, names, logos or look. The cast is ours: **Brass** (brass automaton, one cyan lens),
  **Madame Noctua** (porcelain owl mask, wide hat, velvet), **Captain Gristle** (eye patch, red beard,
  bicorne). Improve them, keep their identity.
- **Performance budget.** One shadow-casting light (the hanging lamp spot). Four point lights max, and
  never add or remove lights at runtime (it forces a shader recompile and a hitch). Share geometries
  and materials, prefer `InstancedMesh` for repeats, keep draw calls reasonable (aim under ~400). No
  per-frame allocations in update loops (reuse vectors). Textures are procedural canvases made once
  at boot (`src/render/textures.js`). No external assets except three.js and Google Fonts.
- **Delivery.** One HTML file. `npm run build` bundles `src/` with esbuild into `dist/index.html`.
  three.js r170 loads from the jsDelivr CDN via the import map in `index.html`.
- **Code style.** Plain modern JS modules. Comments only for a non-obvious why. Keep the existing
  module boundaries (below).

## Architecture (data flows top to bottom)

| Module | Owns |
|---|---|
| `src/model/rules.js` | Pure rules. Game state, legal actions, `startRound/play/challenge/pullTrigger`. No DOM, no three. |
| `src/model/ai.js` | Pure AI policy over `publicView` (never sees hidden hands). |
| `src/director.js` | Async game flow. Asks the model, then stages events (cards, camera, characters, audio, HUD). Every await goes through `step()` so quitting cancels cleanly. |
| `src/render/core.js` | Renderer, scene, camera object, post chain (sanitize, bloom, output, grade), quality ladder, black-frame fallback. |
| `src/render/motion.js` | `Mover` (timed eased flights plus critically damped springs), `smoothDamp`, easings. |
| `src/render/camera.js` | Seated camera rig. Base view tracks the director's focus. Player head-turn from the pointer or touch drag. |
| `src/render/cards.js` | Card meshes, hand layouts (player hand lives in camera space), pile, reveal. |
| `src/render/characters.js` | The three characters, procedural animation, reactions (`lean`, `tremble`, `flinch`, `relief`, `out`), tells. |
| `src/render/world.js` | Room, bar, lamp, table, props, lights, haze and dust. |
| `src/render/gun.js` | Revolver model and its motion (drum spin, hammer, kick, muzzle flash). |
| `src/ui.js` + `index.html` | HUD, menus, settings, stats, trigger button, all CSS. |
| `src/audio.js` | Synthesized sound, music, ambience. |
| `src/main.js` | Boot, pre-warm, frame loop, input. |

Scale is metres. The table top is at y = 0, centred at the origin. The player sits at +z. Opponents
sit on a circle of radius 1.32 (`SEAT_RADIUS`), and each character group's local +z faces the
table centre.

## Verification contract (run these before you report)

```
npm install            # first time in a fresh worktree
npm test               # model tests, must pass
npm run build
node scripts/verify.mjs --size 960x540      # desktop play-through, screenshots in artifacts/
node scripts/verify.mjs --size 390x844      # phone play-through
node scripts/verify.mjs --soak 1 --size 480x270
```

`verify.mjs` exits non-zero on any page error or console error. Screenshots land in `artifacts/`.
Open them with the Read tool and actually look at them. The headless browser renders on the CPU
(SwiftShader), so it's slow. A 960x540 play-through takes a few minutes. Don't treat its frame
times as real GPU numbers. For a focused look at one thing, write a tiny Playwright script in
`/tmp` that loads `dist/index.html` the same way `verify.mjs` does (same route table for the
vendored three.js) and screenshots just that.
